# 中国场景补充提示词 10 条

> 本文件是中文本地化版本新增内容，上游没有对应章节。提示词可直接粘到千问、DeepSeek、Kimi、豆包等国内模型上使用。
> 用法：先把「输入」部分换成你自己的材料，再发；每条后面附了使用提示。

## 1. 写周报

```
你是我的职场助理。根据下面这周做的事情，写一份周报，分三块：本周完成、遇到的问题、下周计划。
要求：每条不超过两句话，动词开头，结果写具体数字；不要空话套话。

本周事项：
（在这里粘贴你这周做的事）
```

使用提示：事项越具体，周报越像样；想给领导看的版本，把「遇到的问题」写成「已采取的动作 + 需要的支持」。

## 2. 改简历

```
你是简历优化顾问。下面是我的简历片段，请按目标岗位的要求改：
1. 每段经历用「动作 + 做了什么 + 结果数据」的结构；
2. 删掉形容词，保留可验证的成果；
3. 输出改后版本和改动说明。

目标岗位：（填写岗位名）
简历片段：
（粘贴简历内容）
```

使用提示：没有数据的成果先别编，标注「待补充数据」，面试时自己填上。

## 3. 写电商详情页卖点

```
你是电商运营。根据下面的产品信息，写一版详情页卖点文案：
1. 开头一句话讲清解决什么问题；
2. 列 5 条卖点，每条一个小标题 + 两句说明；
3. 语气口语化，不写「极致」「顶级」这类空词。

产品信息：
（粘贴产品参数、使用场景、用户评价）
```

使用提示：把差评和退货原因也贴进去，让模型补对应的顾虑回应。

## 4. 写公文通知

```
你是行政公文写作助手。根据下面的要点，写一份内部通知：
1. 标题 + 背景 + 具体安排（时间、对象、要求）+ 联系方式；
2. 语气正式但不生硬，段落简短；
3. 结尾留落款和日期占位。

要点：
（粘贴通知要点）
```

使用提示：涉及制度、奖惩、费用的内容，发出去前务必人工核对一遍。

## 5. 做培训课件提纲

```
你是课程设计师。下面是我要讲的主题，请出一份培训课件提纲：
1. 分 5–7 页，每页写标题、要点、一个互动提问；
2. 开头放一个真实场景问题，结尾放 3 道练习题；
3. 面向零基础学员，术语第一次出现要解释。

主题：（填写主题）
```

使用提示：提纲出来后，挑一页让模型扩成逐页讲稿，比一次要整套讲稿更容易把控质量。

## 6. 拆解甲方需求

```
你是项目交付负责人。下面是甲方提的需求，请拆成：
1. 必须做的功能清单；2. 有歧义、需要二次确认的点；3. 可能延期或加价的风险项。
每条给一句话理由。

需求原文：
（粘贴甲方需求）
```

使用提示：歧义点先找甲方书面确认，别自己脑补，避免后期扯皮。

## 7. 写客服回复

```
你是客服主管。下面是用户的投诉记录，请拟一条回复：
1. 先共情，再说明处理动作和时限；
2. 不甩锅、不承诺做不到的事；
3. 语气礼貌，长度控制在 150 字内。

用户原话：
（粘贴聊天记录或投诉内容）
```

使用提示：涉及退款、赔偿的最终口径，按公司政策走，不要让模型替你承诺金额。

## 8. 写短视频口播脚本

```
你是短视频编导。下面是这条视频要讲的产品/观点，写一份 60 秒口播脚本：
1. 前 3 秒给一个抓人的问题或反常识结论；
2. 中间分 3 点讲，每点配一句画面提示；
3. 结尾给一个明确的行动引导。

主题：（填写主题）
```

使用提示：先出 3 个开头方案选一个，再展开全稿，完播率更高。

## 9. 总结长文档

```
你是阅读助理。阅读下面的长文档，输出：
1. 三句话核心结论；2. 关键数据列表；3. 还需要进一步查证的点。
不要补充文档里没有的信息。

文档内容：
（粘贴长文或链接对应内容）
```

使用提示：文档很长时分段粘贴，每段先小结，最后再汇总，减少遗漏。

## 10. 面试对练

```
你是面试官。针对下面这个岗位，向我提 5 个面试问题，一次只问一个；我回答后，你先指出回答里的漏洞，再给一版更好的答法，然后问下一个。

岗位：（填写岗位名）
```

使用提示：对练完让它把「你的薄弱点 + 改进动作」整理成一张清单，方便后续补。

---

## 使用原则（对应上游入门指南的建议）

- 指令放开头，上下文和输入数据分开写，必要时用 `###` 分隔。
- 要什么格式就给格式示例；要什么风格就说清受众（如「给高中生讲」「150 字以内」）。
- 说「要做什么」，少写「不要做什么」。
- 一条提示词跑不通，先加示例和细节，而不是一次堆太多要求。
